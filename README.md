# facet-studio

Author, publish, and install agent facets from your AI assistant. facet-studio provides skills, commands, and an agent that drive the facet CLI end to end — from scaffolding a new facet to publishing it to the registry.

## Assets

| Type | Name | Purpose |
|------|------|---------|
| Skill | using-facets | Load before any facet operation to ensure the facet CLI is installed and current, then route work through facet instructions. |
| Skill | authoring | Guidelines for authoring quality facet assets: naming rules, manifest metadata, adapter config, and content conventions. |
| Agent | facet-author | End-to-end facet authoring specialist that owns creation and revision of facets — scaffolding, asset content, metadata, build, verify, and publish. |
| Command | facet-create | Scaffold a new facet project headlessly. |
| Command | facet-modify | Edit a facet asset or its metadata headlessly. |
| Command | facet-build | Validate the current facet and build the distributable archive. |
| Command | facet-publish | Publish the built facet to the registry, handling auth and version bumps. |
| Command | facet-add | Add one or more facets to this project and install them. |
| Command | facet-update | Update installed facets to newer versions. |
| Command | facet-remove | Remove facets from this project and uninstall their assets. |
| Command | facet-list | List the facets installed in this project. |

## Installation

### Claude Code / Claude Desktop

Add facet-studio to your Claude workspace:

```bash
/plugin marketplace add <path-or-repo>
/plugin install facet-studio@facet-studio
```

For local development, try facet-studio before installing:

```bash
claude --plugin-dir ./plugin
```

Note: Desktop app cowork sessions load plugins and skills enabled on claude.ai, not from local directories.

### Facet Projects

Once facet-studio is published to the registry, add it to any facet project:

```bash
facet add facet-studio
```

Until then, reference the local path in your facet project:

```bash
facet add <path-to-this-repo>
```

### Codex

Use facet-studio with Codex by materializing skills and commands into Codex's load directories:

```bash
facet adapter add codex
facet add facet-studio
```

Skills and commands are materialized into `.agents/`, and agents into `.codex/agents/*.toml`. Codex support is CLI-driven materialization into Codex's load directories.

## Development

The development loop for facet-studio is:

```bash
facet modify         # Edit a skill, agent, or command
facet build --verify # Validate and build
bun scripts/build-plugin.ts  # Build the plugin
bash scripts/verify-install.sh  # Verify installation
```

## Generated Plugin Directory

The `plugin/` directory is generated by the build process. Never edit files in `plugin/` by hand — any changes will be overwritten.
